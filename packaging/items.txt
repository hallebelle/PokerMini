# POKER MINI - items.txt: the names and info texts of the items (online store, fridge, her give page).
# Edit with Notepad (plain text). Keep the name items.txt next to the game. The full guide is TEXT_GUIDE.txt. Delete this file to get a fresh copy.
# [KEY] starts an item (do not rename the keys). Lines are  FIELD = text  and may be left out: the built-in text is used then.
#   NAME   the item's name (23 characters at most)          INFO    the small line under the price in the store (35 characters)
#   DESC   the info page that opens with Y (5 lines of 28 characters, about 140 characters)   GIVE   its name on her give page (20 characters)
#   BOUGHT the note after you buy it (36 characters)
# Prices, romance values and days are NOT here: they are part of the game rules. If you change a number in a text, only the text changes.
# Anything the game refuses is skipped and written to text_log.txt; the built-in text is used instead. Plain characters only: A-Z 0-9 and . , ! ? ' " - : ; ( ) $ & + = / * < > @ # %
